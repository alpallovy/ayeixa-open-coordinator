# Ayeixa OpenCoordinator

> Lightweight multi-agent orchestration spine and intent routing framework for autonomous TypeScript systems.

## Overview
Ayeixa OpenCoordinator is an open-source component developed under the Ayeixa Public-Good Flywheel.
It provides modular, high-reliability infrastructure licensed under permissive **Apache-2.0**.

## Quick Start
```bash
npm install @ayeixa/open-coordinator
```

```typescript
import { init } from '@ayeixa/open-coordinator';

// Example Usage
init()
```
