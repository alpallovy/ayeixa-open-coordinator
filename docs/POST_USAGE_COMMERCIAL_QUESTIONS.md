# Post-usage commercial questions (optional)

Answer **only if you actually tried** the project (`npm run quicktry`, `npm test`, or a real integration).

Paste into your feedback comment on the repo Discussion thread.

See the full template in this repository’s docs or the [OpenCoordinator copy](https://github.com/alpallovy/ayeixa-open-coordinator/blob/main/docs/POST_USAGE_COMMERCIAL_QUESTIONS.md).

**Questions:**

1. Would a hosted version help? (yes / no / maybe + why)
2. Would managed maintenance help? (yes / no / maybe)
3. Would integration or priority support be valuable? (yes / no / maybe)
4. Would your team budget for this if it solved the problem? (yes / no / unknown)

Explicit answers only — vague interest is not WTP evidence.
